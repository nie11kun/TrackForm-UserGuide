软件安装与启动

软件安装与启动

本节介绍如何在 Windows 系统中安装、启动和升级 TrackForm 星形套球道成型刀具设计软件，以及如何管理软件生成的用户数据文件。

1. 软件安装

TrackForm 提供标准的 Windows 64 位安装包（文件名格式如 TrackForm-1.0.1-limited-win64.msi）。

安装步骤

  1. 运行安装程序：双击下载的 .msi 安装包文件，启动简体中文安装向导。
  2. 选择安装目录：默认安装路径为 C:\Program Files\TrackForm\，您也可以根据需要修改目标文件夹，点击 下一步。
  3. 完成安装：等待文件复制完成后点击 完成。安装程序会自动在 Windows 桌面 和 开始菜单 中创建 TrackForm 快捷方式。

硬件加密狗说明：如果您使用的是带加密狗保护的授权版本，请在启动软件前将配套的 USB 加密狗插入电脑接口，软件启动时会自动完成授权识别。

2. 软件启动

  • 双击桌面上的 TrackForm 图标（或从开始菜单点击 TrackForm）即可启动软件。
  • 软件启动后会自动最大化窗口，并自动恢复您上一次关闭软件前保存的全部参数与界面状态。
  • 启动后界面处于就绪状态，状态栏提示 已恢复上次的设置。请点“计算”开始（首次启动显示默认参数），点击左侧绿色的 ▶ 计算 (F5) 按钮即可开始计算。

3. 软件升级

当获取到新版本的 TrackForm 安装包（.msi）时：

  • 无需手动卸载旧版本：直接双击新版本的 .msi 安装包进行安装，安装程序会自动识别并平滑替换旧版本程序文件。
  • 历史数据完全保留：升级安装不会清除或覆盖您保存在用户数据文件夹中的参数文件（.json）、导出图纸（.dxf / .csv）以及上次的界面设置。

4. 用户数据文件夹结构

为了避免操作系统的权限限制并妥善保存您的工作成果，TrackForm 会自动在您的 Windows 用户主目录下创建专属的数据文件夹：

  • 默认路径：C:\Users\<您的用户名>\TrackForm\（即 %USERPROFILE%\TrackForm\）
  • 快捷打开方式：在软件顶部菜单栏点击 帮助(H) →\rightarrow→ 打开数据文件夹（上次设置、参数、导出），即可直接在 Windows 资源管理器中打开该目录。

该文件夹包含以下内容：

文件 / 子文件夹 用途说明
last_session.json 自动记忆文件：每次计算成功后及关闭软件时，软件会自动将当前所有输入参数、高级参数展开状态、当前选中的图形页签以及最近使用的文件夹路径保存在此文件中，下次启动时自动恢复。
params\ 参数文件夹：通过菜单 文件 →\rightarrow→ 保存参数… (Ctrl+S) 或 载入参数… (Ctrl+O) 时默认打开的目录，用于存放各产品型号的参数配置（.json）。
output\ 导出文件夹：点击左侧 6 个导出按钮（导出 DXF 图纸或 CSV 数据表）时默认打开的保存目录。
