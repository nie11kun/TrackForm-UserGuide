# 第八章：典型工程应用案例实战

前七章详细介绍了软件的各个参数、结果指标、可视化图表与数据导出格式。在实际工程工作中，工程师最常面临的问题是：**“我拿到了一张客户发来的星形套零件图纸，我该按什么顺序把图纸变成车间能直接用的刀具 DXF 和点表？”**

本章精选了 **4 个最具代表性的真实工程实战案例**，手把手带您走完从“识图录入 → 求解校验 → 优化调整 → 导出交付”的全流程。

---

## 四大实战案例导航与适用场景对照

| 案例编号 | 案例主题 | 对应客户图纸特征 | 核心掌握技能 | 详细教程链接 |
| :---: | :--- | :--- | :--- | :--- |
| **案例一** | **标准椭圆球道精确与单圆弧刀具设计 (`AC3300-G`)** | 图纸标注椭圆截面（或给定接触角 $\alpha=42^\circ$、相似度 $k=1.04$） | 标准设计流程、单圆弧替代可行性判定、缩短 `刀尖高度` 增强刀头刚性 | [8.1 案例一：标准椭圆球道刀具设计](case1_ellipse.md) |
