# 8.1 案例一：标准椭圆球道精确与单圆弧刀具设计 (`AC3300-G`)

## 一、任务背景与零件图纸参数

某型号固定式球笼万向节星形套（代号 **`AC3300-G`**，内置于软件 **`文件(F) → 载入示例参数 → AC3300-G_参数`**）采用标准椭圆法向截面球道。客户图纸给出的核心设计参数如下：

| 图纸标注项目 | 图纸数值 | 转换后填入软件的参数名称与数值 |
| :--- | :--- | :--- |
| **钢球规格** | $25/32^{\prime\prime}$ ($\varnothing 19.84375\text{ mm}$) | 基本参数 `钢球直径 Dw` = **`19.844`** mm |
| **节圆直径 (PCD)** | $\varnothing 62.464\text{ mm}$ | 基本参数 `节圆直径 PCD` = **`62.464`** mm |
| **球道中心偏心距 ($e$)** | $4.27\text{ mm}$ | 基本参数 `球道偏移 e` = **`4.27`** mm |
| **球道截面类型** | 椭圆截面 (Elliptical) | 基本参数 `截面类型` = **`椭圆`** |
| **名义接触角 ($\alpha$)** | $42^\circ \pm 2^\circ$ | 基本参数 `接触角 α` = **`42.0`** °，高级参数 `接触角下限/上限` = **`40.0` / `44.0`** |
| **曲率比 / 相似度 ($k$)** | $1.04$ | 基本参数 `定义方式` = **`给定相似度`**，`相似度 k` = **`1.04`** |
| **星形套外球面直径** | $S\varnothing 61.113\text{ mm}$ | 基本参数 `外球面直径` = **`61.113`** mm |
| **星形套总宽度 ($W$)** | $23.1\text{ mm}$ | 基本参数 `工件宽度 W` = **`23.1`** mm |
| **外球面球心至左端面距离 ($H$)** | $13.31\text{ mm}$ | 基本参数 `球心至端面 H` = **`13.31`** mm |
| **中心花键孔直径** | $\varnothing 26.907\text{ mm}$ | 高级参数 `内孔直径` = **`26.907`** mm |
| **球道法向轮廓度公差** | $0.02\text{ mm}$ ($\pm 10\ \mu\text{m}$) | 高级参数 `轮廓度公差` = **`0.02`** mm |

**设计目标**：
1. 求解切入角 $\beta = 36^\circ$ 下的精确成型刀具廓形；
2. 评估是否可以直接采用**单圆弧近似刀具**加工（简化外圆磨床砂轮金刚轮修整）；
3. 将刀尖高度从默认的 `9.922 mm` 缩短优化为紧凑强壮的平顶（`6.2 mm`），并导出最终生产图纸。

---

## 二、分步操作流程

### 第一步：载入参数并执行计算
1. 启动 TrackForm（或点击顶部菜单 **`文件(F) → 恢复默认设置`**，因为软件出厂默认参数即为 `AC3300-G`）；
2. 核对左侧基本参数与上表完全一致；
3. 按键盘 **`F5`**（或点击 **`▶ 计算刀具廓形`**）。

---

### 第二步：核对计算结果与安全校验指标
观察左侧下方的 **`计算结果`** 面板：
1. **核对椭圆截面参数**：
   * `椭圆半轴 a = 10.1762  b = 10.6436  uc = 0.6929`；
   * `顶隙 = 0.0287 mm [0.019~0.04] OK`（位于合格区间内）；
   * 合成球道中心轨迹半径 `轨迹半径 Rp = 31.5225 mm`。
2. **记录有效接触段高度范围**：
   * `接触段 r: 7.9269 ~ 10.1384 mm`
   * `接触段 z: -0.1747 ~ 6.0205 mm`（注意：**有效接触段最高只到 `z = 6.0205 mm`**！）
   * `刀头最大直径 = 20.2768 mm`
3. **确认加工安全性**：
   * `廓形单调性: 通过`，`包络过切检查: 通过 (最小间隙 0.8588 mm)`；
   * `反向仿真最大偏差 = 0.034 μm`（无任何过切或工作面欠切）。

---

### 第三步：评估单圆弧近似替代可行性
1. 按 **`Ctrl + 6`** 切换到 **[Tab 6：圆弧近似刀具](../5_tabs_charts/tab6_arc.md)** 标签页；
2. 查看中下子图的 `切出球道法向偏差`、右上子图的钢球实际落座核对框、左下子图的 `球道底局部放大` 以及左侧结果面板的 `■ 四、圆弧近似刀具` 分块：
   * 取整后单圆弧半径：**`R = 12.3600 mm`**；
   * 圆心坐标：**`圆心 -2.1920 / +1.0710`**（位于中心轴对侧，距钢球中心朝刀柄方向 `1.0710 mm`）；
   * 下端相切圆柱直径：**`圆柱 Ø20.3360 mm`**；
   * **与设计截面偏差：`3.78 μm（轮廓度 ±10） 合格`**（远小于图纸允许的 $\pm 10\ \mu\text{m}$ 红色公差虚线带！）；
   * **钢球实际落座指标**：`实际顶隙 = 0.0325 mm [0.019~0.04] OK`，`实际接触角 = 41.988° [40~44] OK`。
3. **工程结论**：完全可以使用 **`R12.360`** 的单圆弧成型刀具替代复杂样条曲线刀具！

---

### 第四步：缩短刀尖高度以增强刀头刚性（实用进阶技巧！）
1. 按 **`Ctrl + 1`** 回到 **`Tab 1：精确刀具廓形`**，可以看到默认 `刀尖高度 = 9.922 mm` 时，从接触段上端（`z = 6.0205 mm`）到刀尖顶面（`z = 9.922 mm`）有一段长达 `3.90 mm` 的浅绿色非工作刀尖段。
2. 点击 **`▸ 高级参数`** 展开高级参数面板，在 **`刀尖与廓形`** 分组中找到 **`刀尖高度`**：
   * 既然有效接触段上端只到 `6.0205 mm`，我们将 **`刀尖高度`** 修改为 **`6.2`**（在接触段上端之上留出约 `0.18 mm` 的安全余量）；
3. 按 **`F5`** 重新计算：
   * 观察 **`Tab 1：精确刀具廓形`**：浅绿色刀尖避空段大幅缩短，刀具前端变为紧凑强壮的宽平顶，总轴向悬伸缩短了 `3.72 mm`；
   * 观察 **`计算结果`**：`接触段（到球道边缘）z: -0.0566 ~ 6.0205` 毫发无损，`精确刀具反向仿真` 侧面最大偏差依然是 **`0.034 μm`**，没有任何红字截断警告！

---

### 第五步：导出生产交付文件
1. 点击左下角的 **`圆弧刀具 DXF`**，保存 `AC3300G_arc_tool.dxf` 下发砂轮修整/刀具磨削车间；
2. 点击 **`星形套截面 DXF`**，保存 `AC3300G_part_section.dxf` 附入机加工艺卡；
3. 点击 **`方程常数（Table 1）`** 和 **`基本轮廓（Table 2）`**，保存 Table 1 和 Table 2 交付三坐标质检室；
4. 按 **`Ctrl + S`**（或点击顶部菜单 **`文件(F) → 保存参数…`**），保存为 `AC3300G.json` 归档备查。
