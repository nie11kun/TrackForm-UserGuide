# 第三章：高级参数设置详解

在左侧控制面板中，点击 **`▸ 高级参数`** 按钮即可展开（变成 **`▾ 高级参数`**）或折叠高级参数区域。

高级参数共包含 **6 个功能组、22 项参数**。对于大多数常规星形套零件，默认高级参数已经针对车间加工与检测进行了优化，**无需每次修改**；当遇到以下工程需求时，可展开高级参数进行精细控制：

1. **控制刀头高度或非工作区避空**：防止刀尖过长、控制球道底非工作区让刀平滑度；
2. **校核机床夹持干涉与内孔壁厚**：设置刀柄球心距、反转刀柄倾角方向、填入星形套内孔直径；
3. **配置全套自动审核公差带**：设置**顶隙上下限**、**接触角跨距上下限**、**接触角下/上偏差**、**PCD 下/上偏差**以及**轮廓度公差**；
4. **定制圆弧近似刀具方案与刀尖延伸**：
   - 选择 **`1~5` 段相切圆弧** 或 **`按审核优化` 单圆弧**；
   - 选择单圆弧 **`审核优化目标`**（`贴合设计截面` / `审核范围硬约束` / `审核范围中值`）；
   - 设置 **`刀尖延伸`**（沿原圆弧延长刀尖而不切深球道，避开尖角磨损）与磨刀尺寸 **`取整位数`**；
5. **控制客户图纸 Table 1 / Table 2 导出格式**：控制基本轮廓采样点数、终点位置与常数基准。
