# 第三章：高级参数设置详解

在左侧控制面板中，点击 **`▸ 高级参数`** 按钮即可展开（变成 **`▾ 高级参数`**）或折叠高级参数区域。

高级参数共包含 **6 个功能组、18 项参数**。对于大多数常规星形套零件，软件的默认高级参数已经针对现场加工与检测进行了优化，**无需每次修改**；但当遇到以下特定工程需求时，您需要展开高级参数进行精细控制：

1. **缩短刀头高度或调整非工作区让刀避空**（防止刀尖过长、控制球道底非工作区过渡平滑度）；
2. **检查机床夹持干涉或绘制完整星形套截面图**（设置刀柄球心距、反转刀柄倾角方向、填入星形套内孔直径）；
3. **按客户图纸公差带配置全套自动审核判据**（设置**顶隙上下限**、**接触角上下限**、**接触角跨距上下限**以及**轮廓度公差**）；
4. **选择单圆弧 / 多段相切圆弧刀具或“按审核优化”求法**（设置**圆弧段数 `1~5` 段**、**单圆弧求法 `拟合精确廓形 / 按审核优化`** 以及磨刀尺寸**取整位数**）；
5. **控制客户图纸 Table 1 / Table 2 导出格式**（控制基本轮廓采样点数、终点位置与常数基准）。
