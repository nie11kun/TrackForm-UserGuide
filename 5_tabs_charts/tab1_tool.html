精确刀具廓形

5.1 Tab 1：精确刀具廓形 (Ctrl+1)

精确刀具廓形 是软件启动后的默认首屏标签页，以 1:1 等比例坐标系 直观展示按包络条件算出的精确球道成型刀具轴截面全貌，并在图上直接标出关键尺寸箭头、切削边界说明以及球道边缘延伸段的局部放大窗。

一、标题栏关键读数、坐标系与图面尺寸标注

1. 顶部标题栏与图面直接尺寸标注

  • 顶部标题栏：精确刀具轴截面廓形【理论值】（原点 = 虚拟钢球中心） 刀柄端面 z = -50；
  • 左侧竖向尺寸箭头 刀尖高度 9.922：直接标出从原点 z=0z = 0z=0（虚拟钢球中心）到刀尖平端面的轴向高度；
  • 下部横向尺寸箭头 最大直径 Ø20.277：直接标出刀头接触段（含边缘延伸）最宽处的最大回转外径，用于选定刀具棒料直径。

2. 坐标轴定义

  • 横轴 r 半径 (mm)：垂直于刀具旋转轴线的径向坐标。中央红色竖直点划线 r = 0 即为刀具旋转中心轴线，左右两侧刀刃关于 r = 0 完全对称。
  • 纵轴 z 沿刀轴 (mm)，刀尖方向为正：沿着刀具旋转轴线的高度坐标。
    • 原点 z = 0：虚拟钢球球心所在的基准水平面（灰色水平点划线）；
    • 向上（+z+z+z 方向）：朝向刀具前端刀尖顶面（切入球道底部深处）；
    • 向下（−z-z−z 方向）：朝向刀头根部及刀柄端面（对应球道外球面开口边缘）。

二、图例、各色曲线与左下角“球道边缘局部放大”窗

在阅读 精确刀具廓形 图时，请对照右下角图例与图面引线重点区分以下 6 组几何元素：

图例 / 标注名称 线型与颜色 工程含义与设计作用
刀头最大外形 绿色粗实线 + 浅绿填充区 勾勒出整个成型刀头的完整回转外轮廓。其中接触段上端分界线以上的浅绿色阴影区域标有文字说明：“刀尖段：不切削，绿线为最大允许外形，不得超出，可在线内修整为倒角/平端”。
接触段（切削，必须精确；到球道边缘） 珊瑚红粗实线 核心工作刀刃！上端带红色引线标注 接触段上端：切出球道底附近，下端红点标注 切出球道边缘（外球面处）（若点表未覆盖到外球面则注明 切出点表末端（未到外球面））。该段刀刃直接包络切削出星形套球道有效工作面，制造与检测时必须严格保证其精度。
边缘延伸段 (0.3 mm) + 左下角局部放大窗 橙色粗实线 + 左下角放大图 在红点（球道边缘外球面处）之外继续朝刀柄侧延伸的一小段刃口（引线标注 延伸末端），为外球面尺寸偏差和装夹定位误差留出余量。由于延伸段很短，左下角内嵌放大窗 球道边缘局部放大：延伸 0.3 mm 自动将该处放大，清晰标出 球道边缘 z ... 红点与 延伸末端 z ... 橙色段！
球道底约束 (R21.572) 蓝色点线 球道底部最低点（半径 R21.572）在刀具轴截面中的投影边界。刀尖段绿色实线向内缩进了 让刀量（默认 0.05 mm），始终保持在蓝色点线内侧，确保刀尖绝不擦伤球道底。
虚拟钢球 灰色细虚线圆 以原点 (0,0)(0,0)(0,0) 为圆心、直径等于钢球直径 DwD_wDw​（默认 19.844 mm）的设计基准球。
36° 线 (切入角 β) 灰色细实线 从原点 (0,0)(0,0)(0,0) 引出、与水平面呈切入角 β\betaβ（图中标有 β=36°）的参考线，加工时始终位于球道法向截面内。

三、工程师看图检查要点

  1. 检查接触段（红线）、边缘延伸段（橙线）与刀尖段（绿线）的过渡：
    • 正常情况下，上端红线平滑过渡为绿色刀尖让刀段，下端红点处继续顺延出橙色边缘延伸段（可在左下角放大窗核对延伸起止坐标）；
    • 若在 点表(CSV) 模式下设置了 边缘延伸 > 0 但点表本身只给到球道边缘，图面右下角会贴心给出橙色提示 边缘延伸 X mm 未生效（点表只到球道边缘...）。
  2. 根据加工工艺优化刀尖段外形：
    • 若觉得默认刀尖高度（9.922 mm）较高，可在高级参数中将 刀尖高度 调小至略大于接触段上端高度（例如对默认参数设为 6.2 ~ 6.5 mm），或在绿色最大允许外形线以内将其修整为平端/大圆角，以提高刀头刚性。
